# 术语表

## 网络与图

- **工程（Project）**：一个目录，含 `project.netlab`、`blocks/`、`extensions/`、`exports/`、`backups/`。
- **网络（Network）**：工程内一张独立的图；一个工程可以有多个网络。
- **节点（Node）**：图上的一次计算，带参数与输出字段。
- **连接（Edge）**：节点之间的传递关系，带传递函数或元件模型。
- **端口（Port）**：节点侧边的连接锚点；器件有引脚（pin）。
- **器件（Device）**：电路模式下带引脚与符号的元件节点。
- **场景（Scene）**：节点、连接与仿真设置的 JSON 快照。

## 工作模式

- **信号流（signal）**：按拓扑顺序传播字典数据；每段输出是一个 `dict`。
- **电路（circuit）**：节点电压法（MNA）求解，牛顿迭代处理非线性；支持工作点与 AC 扫描。
- **矢量（vector）**：二维状态与非线性动态源，强调相图与轨迹。
- **有限元（FEM）**：二维热传导场，Q4 双线性单元 + 后向欧拉；独立工作区。

## 仿真与观测

- **dt**：仿真步长；`step` 是已推进的步数。
- **运行 / 暂停 / 单步 / 重置**：控制仿真线程；启动后默认停止。
- **探针（Probe）**：从节点数据里挑出要画曲线的字段。
- **回放（Replay）**：在已录制的帧之间拖动查看，不影响实时运行。
- **旁路分析（Analysis）**：不改变主仿真的支路/灵敏度分析视图。
- **相图（Phase）**：二维状态轨迹图，读取 `x/y` 或 `vx/vy`。

## 外观与扩展

- **设计令牌（Token）**：颜色、字体、间距、动效、性能档的变量，见 `style.css` 顶部。
- **动效档**：关 / 低 / 中 / 高，控制面板与文档的位移时长。
- **UI 性能档**：性能 / 平衡 / 画质，影响模糊、阴影与画布像素比。
- **模块（Block）**：可复用的子网络，存为 `.block`。
- **扩展（Extension）**：工程或全局目录里的自定义节点/函数实现，在服务端受限执行。
- **模板（Template）**：空白场景或示例网络的生成器，例如信号链示例。
