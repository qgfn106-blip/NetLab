# 非线性 / 非定常闭环求解与网络分析规划

> 本文件是**分阶段实施规格**。2026-11-04 按用户「先计划规划好，还是先不开工」完成规划；2026-11-05 用户确认「按照文档开始任务」后进入实施：`status` 已改为 `ready-for-agent`，P1–P4 已完成，P5 继续，全部完成后再改 `implemented`。

## 1. 起因与目标

用户原话（2026-11-04）：

> 要做非线性，非定常系统所以加上newtone环，再加上之前的计划，同步文档需求，并且按照文档规划先计划规划好，还是先不开工

需要一起纳入规划的三组能力：

1. **求解器**：信号流当前按拓扑序逐节点更新，遇到无状态节点的代数环只能靠自动 `z⁻¹` 打断；这会把「同一时刻的代数约束」改成「延迟一拍的动态」，模型语义被悄悄改变。要支持非线性、非定常闭环，必须有显式的代数环求解，Newton 环是其中一层。
2. **线性网络分析**：在 DAG 上已经有单节点 `transfer_function` 的 Bode / 阶跃 / 零极点；要把整张线性网络的总传函、Bode 相位、极点稳定性做出来，用于闭环设计验收。
3. **状态与数据呈现**：相平面需要真实状态（`x`、`vx` 等），不能从总传函反推；同时要有独立播放条和数据分析，才能把预计算轨迹当作可检查的工程结果，而不是一张动画。

### 1.1 补充确认（2026-11-04）

用户进一步确认，以下三项也纳入本规划，作为 R37 / R38 的明确验收项：

1. **线性网络总传函预计算**：支持串联 / 并联 / 反馈环；延迟边在 z 域按 `z⁻¹` 精确处理，s 域不伪装成有理式、明确标注近似；输出总传函与 Bode 幅相。
2. **相平面基于网络状态**：直接收集 `transfer_function` / 状态空间等节点的真实状态做预计算，不从总传函反推，也不要求用户另建矢量系统。
3. **相平面独立播放条与数据分析**：时间轴、状态轨迹、相图联动，支持单独播放 / 步进 / 查看；提供峰值、超调、稳态、调节时间与 CSV 导出。

本轮仍只做规划与文档同步，不写实现代码。

目标不是「一次做成 Simulink/Modelica」，而是把 **显式语义 → 状态断点 → SCC 线性求解 → Newton 非线性 → 网络分析 → 状态呈现** 这条路径拆成可独立验收的阶段，保证每一步都不破坏现有 504 条测试所覆盖的行为。

## 2. 范围与非目标

### 2.1 范围内

- 节点 / 边增加求解语义标签（线性、直接馈通、有状态、时变、非线性）。
- 执行图从「全图拓扑序」改为「状态断点切分 + SCC 缩点 + SCC 内求解」。
- 线性 SCC 用 `(I - W) y = b` 直接解；非线性 / 时变 SCC 用阻尼 Newton。
- 显式延迟边语义：读上一拍；自动 `z⁻¹` 仅作为兼容回退，并给出可见提示。
- 线性网络总传函、Bode（幅值 + 相位）、极点 / 稳定性。
- 相平面所需状态的预计算、独立播放条、基础数据分析（超调、峰值、稳态、调节时间等）。
- 全程保留旧工程兼容；默认行为变更必须单列决策与回归测试。

### 2.2 非目标（本轮规划明确不做）

- 不做完整 DAE / 指标-1 降阶 / 自动事件检测；不引入 Modelica 式方程建模。
- 不做 MIMO 总传函、非线性系统的小信号自动线性化、频域非线性描述函数。
- 不做任意代数环的全局唯一性证明；无解 / 多解时明确报错，不静默给一个值。
- 不把电路域的节点电压法（MNA）并入这套信号流求解器；两边共享「SCC + 线性求解」思想，但不共享状态。
- 不在本轮改前端交互；R38 的播放条 / 数据分析只做规划与接口预留。

## 3. 需求拆分

### R36 非线性 / 非定常闭环求解（状态断点 + SCC + Newton）

**原话依据**：用户要求「非线性，非定常系统所以加上newtone环」。

**解读**：信号流的执行顺序不能再假设「所有入边都来自已经算完的节点」。有状态节点（积分器、传递函数、延迟）的输出只依赖上一拍状态，是天然断点；没有状态节点的环是代数环，必须在同一时刻求解。线性环直接解线性方程组，非线性 / 时变环用 Newton 迭代。

**落地形态**：

- 节点元数据增加：`linear`、`stateful`、`direct_feedthrough`、`time_varying`、`nonlinear`。
- `transfer_function`：`stateful=True`，`direct_feedthrough=(D != 0)`；`integrator` / `delay`：`stateful=True`；`sum` / `gain` / `pass`：线性直接馈通；`expression`：AST 判仿射，仿射归线性，否则非线性；`clip` / 查表 / 分段函数归非线性。
- 执行图：先切出有状态节点作为断点，剩余直接馈通子图求 SCC；SCC DAG 按拓扑序执行；每个 SCC 内解代数约束。
- 线性 SCC：`y = b + W y` → `(I - W) y = b`；奇异时抛 `AlgebraicLoopError`，消息列出环节点与边。
- 非线性 SCC：`F(y) = 0`，阻尼 Newton + 线搜索；雅可比优先解析，缺失时用有限差分；`max_iter`、`tol`、残差与失败节点写入错误。
- 时变：参数表达式在每拍按 `t` 求值；Newton 迭代内部冻结该拍的参数。
- 兼容：默认仍保留现有自动 `z⁻¹` 回退，但记录「本环被自动延迟」并在 UI/日志可见；显式 `delay=True` 优先，不被自动策略覆盖。

**验收**：

- 两增益代数环（无状态节点）不再被自动 `z⁻¹` 改写；线性解与解析值一致。
- 有状态节点参与的环仍按状态断点执行，结果与现有行为一致。
- 非线性单环（如 `y = tanh(y) + u`）Newton 收敛；无解 / 发散时报中文错误，不返回伪值。
- 时变增益 `k(t)` 在每拍变化，闭环响应随 `t` 改变。
- 全量 pytest 只增不减；旧工程默认结果不变（除显式开启新策略的用例）。

### R37 线性网络总传函与 Bode 相位

**原话依据**：用户此前要求「参考 Simulink 的传递函数 / Bode」，并要求把「之前的计划」一起纳入。

**解读**：单节点 TF 已有；闭环设计需要从整张线性网络直接得到 `G(s)`，并画幅值 + 相位，而不是手工串联 / 并联 / 反馈拼公式。

**落地形态**：

- 对纯线性网络，构造全局状态空间互联：`x' = A x + B u`、`y = C x + D u`；节点内部状态与连线代数关系一起装配。
- 总传函 `G(s) = C (sI - A)^{-1} B + D`；Bode 用 `G(jω)`，离散网络用 `G(e^{jω dt})`；相位与幅值同一套频点。
- 延迟边在 z 域精确为 `z⁻¹`；连续 s 域不伪装成有理式，必要时标「含延迟，s 域为近似」。
- 有代数环时先走 R36 的 SCC 求解，再在平衡点附近做线性化；纯线性环可直接消元，不迭代。

**验收**：

- 串联 / 并联 / 单位负反馈三个标准网络的总传函与手工推导一致（误差 <1e-9）。
- 一阶 `1/(s+1)` 闭环 Bode 在 `ω=1` 的幅值 / 相位与单节点分析一致。
- 含显式 `z⁻¹` 的网络在 z 域 Bode 与逐拍仿真一致；s 域结果明确标注近似。
- 非线性网络调用总传函时返回明确「不支持 / 需先线性化」错误，不静默给线性化结果。

### R38 相平面状态预计算 + 独立播放条 + 数据分析

**原话依据**：用户此前问「相图为什么必须用矢量系统」「相图能不能用拉氏 / 傅里叶画」，并同意把之前的计划一起规划。

**解读**：相平面不是总传函的后处理，而是状态轨迹的几何。需要把网络内部状态暴露成可选通道，预计算轨迹，再用独立播放条与数据分析查看。

**落地形态**：

- 状态通道：`StateSpaceModel.state`、积分器状态、延迟历史等注册为 `state:<node>:<index>`；信号流节点默认只暴露 `value`，但分析面板可选择内部状态。
- 预计算：一次运行记录所选状态对与时间；支持 `x/y`、`vx/vy` 选择；不要求用户把系统改成矢量模式。
- 独立播放条：时间轴、播放 / 暂停 / 步进 / 循环、当前帧数值；与主仿真时间轴解耦。
- 数据分析：峰值、超调、稳态值、调节时间、相位图轨迹长度 / 包围面积等；导出 CSV。
- 线性系统可用可控标准型状态画「规范型相图」，但 UI 明确标注 realization；非线性必须积分 `ẋ=f(x)`。

**验收**：

- 欠阻尼二阶 `4/(s²+1.2s+4)` 的相图与解析椭圆一致（无阻尼）或收敛螺旋（有阻尼）。
- 同一工程切换 `dt` 后相图轨迹随步长收敛。
- 播放条可独立于主运行暂停 / 步进；数据面板数值与录制帧一致。
- 信号流节点不暴露状态时，面板给出「该节点无状态通道」的中文提示，不显示空白图。

## 4. 架构决策

### D92 求解器路线：状态断点优先 + SCC + Newton，暂不上全 DAE

**结论**：先做「有状态节点切分 + 直接馈通 SCC + 线性代数解 + 非线性 Newton」，不做完整 DAE、不自动做指标降阶。理由：当前模型是信号流（有向、单值、显式状态），不是方程建模；DAE 会引入变量初始化、一致性投影、事件检测等一整套问题，超出当前收益。SCC + Newton 已能覆盖用户提出的非线性 / 非定常闭环，且能保留现有节点模型。

### D93 总传函走全局状态空间互联，不靠纯符号梅森

**结论**：线性网络总传函用全局 `A,B,C,D` 与 `C(sI-A)^{-1}B+D` 计算；Mason 增益公式只作为小图校验 / 解释，不作为主实现。理由：状态空间能统一处理多状态、代数环、延迟（z 域），并与现有 `StateSpaceModel` 复用；纯符号在有环、多输入多输出时容易爆炸且难验收。

### D94 相平面从网络状态直接预计算，不从总传函反推

**结论**：相平面数据来源是节点内部状态轨迹；总传函只用于 Bode / 极点 / 稳定性，不用于重建相图。理由：`H(s)` 是零初值输入-输出关系，丢失状态初值、内部几何与非线性；用 `X(s)=(sI-A)^{-1}[x0+BU(s)]` 反拉氏只对线性系统且需要显式 `x0`，不能作为通用实现。

## 5. 求解器设计细节

### 5.1 节点语义标签

| 标签 | 含义 | 例子 |
| --- | --- | --- |
| `linear` | 输出对输入仿射 | sum、gain、pass、线性 TF |
| `stateful` | 输出依赖上一拍状态，可作断点 | integrator、transfer_function、delay |
| `direct_feedthrough` | 当前输出直接依赖当前输入 | gain、sum、D≠0 的 TF |
| `time_varying` | 参数随 `t` 变 | `k(t)` 增益、时变 TF |
| `nonlinear` | 输出对输入非线性 | tanh、clip、查表、分段 |

`expression` 用 AST 判定：只含 `+ - * /` 与常数系数 → 仿射；含 `sin/cos/exp/tanh/...` 或变量相乘 → 非线性。人工填写的 `G(s)` 视为声明式 LTI，校验 proper / 有理 / 常系数即可，不做「矩阵数值判断」。

### 5.2 执行图

1. 标记所有 `stateful` 节点为断点；断点输出取上一拍状态（或初值）。
2. 在剩余直接馈通子图上求强连通分量（SCC），缩点得到 DAG。
3. 按 DAG 拓扑序执行每个 SCC：先算外部输入，再解 SCC 内代数约束，最后写输出。
4. 全部 SCC 完成后，统一推进 `stateful` 节点的状态（`x[k+1] = f(x[k], u[k])`）。
5. 延迟边不参与 SCC 依赖；它读源节点上一拍输出，写入目标当前输入。

### 5.3 线性 SCC

对 SCC 内每个节点写 `y_i = b_i + Σ_j W_ij y_j`，组装 `(I - W) y = b`：

- 用带部分主元的 LU / `numpy.linalg.solve`；
- 奇异 → `AlgebraicLoopError`，消息含 SCC 节点名、边名、建议「插入显式延迟或状态节点」；
- 规模上限与现有矩阵限制一致（12×12 以内优先，超出给性能提示）。

### 5.4 非线性 / 非定常 SCC：Newton

- 残差 `F(y) = y - f(y, u, t)`；
- 初值：上一拍解，否则 0；
- 雅可比：解析优先；否则前向差分，步长 `max(1e-7, 1e-6*|y|)`；
- 阻尼：`y_{k+1} = y_k - α J^{-1} F`，`α` 从 1 开始，残差下降不足则减半（最多 8 次）；
- 收敛：`||F||∞ < tol`（默认 `1e-9`）或 `||Δy||∞ < tol`；
- 失败：`max_iter`（默认 50）后抛 `NewtonConvergenceError`，带残差、迭代数、节点名；不返回「差不多」的值；
- 时变参数在该拍冻结；跨拍重新求值。

### 5.5 延迟与自动回退

- 显式 `delay=True`：严格读上一拍，优先级最高。
- 自动 `z⁻¹`：只在 SCC 无状态节点且用户未显式指定时启用，作为旧工程兼容；启用时记录 `auto_delayed_edges`，UI 标黄并提示「该环被自动延迟，模型语义已改变」。
- 有状态节点（D=0 的 TF、积分器、延迟）本身是断点，不再自动加延迟。
- 新增工程默认「显式优先」；旧工程加载时保持原自动行为，避免静默改变结果。

### 5.6 错误与诊断

统一错误类型：

- `AlgebraicLoopError`：线性 SCC 奇异 / 无唯一解；
- `NewtonConvergenceError`：非线性迭代失败；
- `UnsupportedLoopError`：SCC 含不支持的节点组合。

错误消息必须包含：SCC 节点、边、残差 / 奇异矩阵维度、建议操作（加状态节点 / 显式延迟 / 改初值）。前端预计算对话框只显示摘要，详情进日志 / 检查器。

## 6. 分析层设计

### 6.1 全局状态空间

- 输入：线性网络 + 选定的源 / 输出节点；
- 装配：节点内部 `A_i,B_i,C_i,D_i` 与连线 `y_j = u_i` 消元；
- 输出：`A,B,C,D`，以及 `G(s)` 的分子 / 分母（若为有理）；
- 延迟边：z 域保留 `z⁻¹`；s 域标「含延迟，近似」。

### 6.2 Bode / 极点

- 频点：默认 `logspace(-2, 3, 500)`，可调；
- 幅值 `20log10|G(jω)|`，相位 `angle(G(jω))`（度，unwrap）；
- 离散网络用 `G(e^{jωdt})`，并在图上标 `z` 域；
- 极点：`eig(A)`；稳定性按最大实部判定，临界 / 不稳定给中文结论。

### 6.3 相平面 / 播放 / 数据

- 状态通道注册表：`state:<node>:<index>`，显示名、单位、所属节点；
- 预计算：`(t, x_i, x_j)` 序列；支持抽样与容量上限；
- 播放：独立时间轴、播放 / 暂停 / 步进 / 循环、当前帧读数；
- 数据：峰值、超调、稳态、调节时间、相图轨迹长度；导出 CSV；
- 规范型提示：线性系统用可控标准型时，图上标注「规范型坐标，非物理状态」。

## 8. 风险与兼容

- **默认行为变化**：自动 `z⁻¹` 改为「显式优先」会改变两增益环结果；必须用工程级开关 + 迁移提示，不能静默切换。
- **Newton 收敛**：非线性环可能无解 / 多解；只报错不猜测；给初值与阻尼参数入口。
- **性能**：SCC 与雅可比增加开销；先做小规模（≤12 状态）验收，再谈大规模。
- **采样语义**：现有 `StateSpaceModel` 先输出旧状态、`Network` 标 `time+dt`；本轮不改，P1 重构时用测试锁定，若改需单列决策。
- **旧工程**：保留 `voltage` / 自动延迟 / 旧采样标签的兼容路径；新增行为通过工程配置显式开启。
