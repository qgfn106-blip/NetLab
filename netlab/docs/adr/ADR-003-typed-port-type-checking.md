# ADR-003: Typed Port 类型检查策略

- **状态**：Proposed
- **决策者**：用户（2026-11-11 正式裁决）
- **关联**：`NETLAB_V2_PLANNING_REVIEW.md` §3、§4；`CORE_ARCHITECTURE_AUDIT.md` P2-B

## 背景

当前节点端口多为无类型/弱类型（以名称和字典数据约定），连接合法性只能在运行时靠数值错误发现，缺少单位与物理维度检查。

## 决策

1. 引入 **PortType**：至少包含类型标识、物理维度/单位、方向、基数/组合方式与可选约束。
2. 类型检查分两层：
   - **静态/装配期**：连接建立、模型编译时做兼容性检查，错误应可定位到具体端口。
   - **运行期**：对动态/插件类型做必要的运行时校验，但不得以运行时校验替代装配期检查。
3. 单位与量纲作为一等信息；允许显式换算，但不得静默丢弃单位。
4. 多端口组合（数组/向量/矩阵）需明确基数规则；插件可注册受支持的类型，但必须通过公开 API。

## 影响

- P2-B 需要最小代表性模型（`sum+integrator`、R/C、2×2 vector、有内部状态动态元件）验证。
- 旧模型需要类型推断/兼容映射，不能强制一次性手工标注。
