# 会话日志（session logs）

本目录保存按日期归档的工程会话记录，用于把「需求/决策」（REQUIREMENTS_AND_RULES.md）、「里程碑」（MILESTONES.md）与「逐轮执行证据」（PROGRESS.md）分开。

## 约定

- 文件命名：`YYYY-MM-DD-主题.md`，主题使用小写短横线。
- 每份会话日志记录：本轮目标、改动文件、验证命令与结果、未完成项、下一步编号。
- 不写入用户名、本机私有路径、私有代理端口、访问令牌或任何环境密钥。
- 当前口径仍以 `REQUIREMENTS_AND_RULES.md`、`PROGRESS.md`、`DOCS_INDEX.md` 为准；会话日志是证据摘要，不替代需求与决策台账。
