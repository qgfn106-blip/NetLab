# 欢迎使用 Netlab

Netlab 是一个本地运行的**可解释仿真环境**：网络用「节点 + 连接」描述，运行时按拓扑顺序传播信号，
或用节点电压法求解电路，或对二维矢量场做非线性积分。每条曲线都能追溯到注册表里的公式与真实源码。

## 三种工作模式

- **信号流**：按拓扑顺序逐段传播字典数据，适合控制系统框图、滤波器、阶跃与方波观察。
- **电路**：节点电压法（MNA）+ 牛顿迭代，配合 GB/T 4728 风格符号与器件引脚。
- **矢量**：非线性动态源、二维矢量连接与相图，适合振子与连续状态实验。

启动时先出现的引导页会让你选择场景；选完后进入该模式的空白场景。工作模式随时可以从
「设置 → 工程 → 工作模式」切换，切换会重建空白场景，请先保存需要保留的内容。

## 五分钟上手

1. **搭网络**：工具栏「节点」在画布中心添加节点；从节点右侧端口拖出即可连到目标节点。
2. **改参数**：双击节点或连接，右侧「检查器」按 ParamSpec 生成表单；每个参数旁的 `?` 给出
   说明、取值、单位与默认、公式四段内容。
3. **看曲线**：右侧「分析 · 信号」勾选变量，点顶部「运行」开始采集；「回放」可在历史帧间拖动。
4. **存工程**：文件菜单「保存工程」写 `project.netlab`；Ctrl+S 同样保存，Ctrl+Shift+E 导出场景 JSON。

> 启动后仿真始终是**停止**状态：需要手动点「运行」或按空格。这是有意设计，避免打开页面就开始耗算力。

## 外观与性能

菜单「设置 → 视图与外观」可以切换主题（跟随系统 / 浅色 / 深色）、强调色、动效程度与 UI 性能。
这些是**跟人走**的全局偏好，保存在 `%APPDATA%/Netlab/settings.json`；图纸风格、GB 符号、网格与
节点样式属于工程，随 `.netlab` 保存。

## 需要帮助时

- 任意参数旁的 `?`：四段式说明卡片，并可跳到实现页。
- 「帮助」菜单：快速上手、界面指南、术语表、常见问题、快捷键。
- `Ctrl+K` 或「工具 → 全局搜索」：跨全部文档搜索。
- 文档窗口是非模态的：可以一边看文档一边操作画布。
