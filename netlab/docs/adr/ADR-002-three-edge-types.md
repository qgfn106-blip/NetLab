# ADR-002: 三型 Edge 语义分离

- **状态**：Proposed
- **决策者**：用户（2026-11-11 正式裁决）
- **关联**：`NETLAB_V2_PLANNING_REVIEW.md` §3、§4；`CORE_ARCHITECTURE_AUDIT.md` P1-B1

## 背景

当前物理拓扑与计算依赖共用 `Connection`/`EdgeRecord`，导致“物理上相连”与“计算上依赖”混为一谈，通用模型无法准确表达图语义。

## 决策

将 Edge 语义显式分为三类：

1. **PhysicalEdge**：物理拓扑连接，描述端口之间的真实物理连接。
2. **DependencyEdge**：计算依赖，描述变量/方程之间的求值依赖或数据流依赖。
3. **LayoutEdge**：布局/展示连接，只影响视图，不进入物理或计算语义。

要求：

- 三类 Edge 各自有类型、合法端点类型与在存储/序列化中的明确字段；不得靠隐式约定区分。
- 物理拓扑边不等于计算依赖边；需要转换时由模型编译/装配阶段显式生成。
- 旧 `Connection` 作为兼容层保留，逐项迁移；不得在未验证前一次性重写。

## 影响

- 需要 P2-C 的兼容层与检查器；P1-B1 审计项据此收敛。
- 现有信号流/电路示例需要迁移映射，作为回归测试集。
