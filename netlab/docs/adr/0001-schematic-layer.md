# ADR 0001：电气拓扑层与图纸布局层分离

- 状态：已接受（2026-10-26）
- 决策者：用户（grill-with-docs 访谈）
- 相关：R18 / R19、D33 / D34、`SCHEMATIC_DRAWING_SPEC.md`、`GLOSSARY.md`

## 背景

电路模式长期把「电气模型」直接当「画图模型」：`node` 是电节点，`edge` 是元件，
符号画在边的中点，引脚没有独立几何，节点/端口是通用渲染的副产品。结果是：

- 元件与连线方向不一致（符号取向依赖路径末段，正交折线末段可能长度 0）；
- GB 符号与网络的衔接靠“边中点”，多引脚器件（运放/比较器/触发器）无法表达真实引脚；
- 拖动画布只能得到“看起来像电路”的图，无法保证引脚、导线、汇合点与电气连接一致；
- agent 没有可执行的绘制规范，每次改图都重新发明规则。

用户明确要求：把「GB 与连接线作为一个整体」，并为 agent 提供绘制文档规划；
同时参考 GB/T 4728（符号）、GB/T 6988.1 与 GB/T 18135（文件/CAD 制图）、
GB/T 5094（参照代号）、GB/T 4026（端子/导体标识）两层规范思路：
国家标准管符号与标识，软件自定布局/连线/交互规则。

## 决策

引入两个**职责分离**的层：

1. **电气拓扑层**（唯一求解口径，现有 `node`/`edge`/参数模型不重写）
   - 元件仍是电气对象；两端元件的引脚绑定 `source`/`target`；
   - 多端器件在 edge 上增加可选 `pins: {引脚名: 节点id}`，`ElementSpec` 声明引脚名/角色/必需性；
   - 引脚绑定必须指向存在的节点，否则报错。
2. **图纸布局层**（可编辑、可自动生成，不影响求解）
   - 每个元件有可选 `layout: {x, y, rot}`；旋转步长 30°（覆盖 60°/90° 及其倍数）；
   - 符号库为每个符号声明局部引脚表（坐标、方向、名称、绑定角色）；
   - 电节点是**网络锚点**（小圆/接地符号），导线从引脚连到锚点；≥3 线相接画实心汇合点；
   - 导线默认正交；引脚轴非水平/垂直时，先沿轴拉一段直线再接正交折线；
   - 自动布局是确定性的（拓扑分层 + 20 网格 + lane 错开），手工布局优先且持久化。

## 后果

**正面**

- 移动元件、拖折线只改布局层，不改变电气网络（拓扑安全）；
- 多引脚符号（运放、触发器、未来的 BJT）有真实引脚几何，能与网络正确衔接；
- agent 有稳定的绘制规范：同一网表生成同样的图，diff 可复现；
- 图形层可独立演进（图纸模式、图框、线宽分级）而不触碰求解器。

**代价/限制**

- 需要新增引脚表与布局数据结构，旧工程要自动生成一次布局；
- 自动布局只保证“确定性 + 不重叠”，不保证“最美观”；
- 非 90° 旋转会引入斜线段，与纯正交图纸有取舍；
- 国标只做“风格相似”，不承诺尺寸公差/完整图框；完整图框、端子号、线号属后续阶段。

## 备选方案（未采用）

- **只给 edge 加 pin1/pin2 坐标**：无法表达运放/触发器的多引脚，也无法把「引脚」作为电气绑定。
- **把元件拆成独立 ElementInstance 多端网表**：最彻底，但需要重写数据模型与迁移，成本过高，暂缓。
- **力导向自动布局**：结果不可复现，agent 无法稳定 diff，不采用。
