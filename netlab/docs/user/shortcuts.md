# 快捷键

## 仿真

- `空格`：运行 / 暂停当前工作区
- `S`：单步推进一个 `dt`
- `R`：重置状态与时间

## 画布与节点

- `A`：在视图中心添加节点
- `F`：适配网络视图
- `Delete`：删除选中的节点或连接
- `双击节点 / 连接`：打开检查器编辑
- `从右侧端口拖出`：连接目标节点并选择传递函数
- `滚轮`：缩放；`中键拖拽`：平移
- `Alt + 拖动`：临时暂停网格吸附

## 编辑

- `Ctrl+Z`：撤销（100 步）
- `Ctrl+Shift+Z`：重做
- `Ctrl+C` / `Ctrl+X` / `Ctrl+V`：复制 / 剪切 / 粘贴（跨网络需确认）
- `Ctrl+A`：全选

## 文件

- `Ctrl+S`：保存工程
- `Ctrl+Shift+E`：导出场景 JSON

## 界面与帮助

- `H`：打开快速上手文档
- `?`：打开快捷键文档
- `Ctrl+K`：文档搜索（聚焦搜索框）
- `Esc`：关闭菜单 / 弹窗 / 设置抽屉 / 文档窗口
- `Enter`（引导页）：进入选中场景

## 鼠标与触摸

- 单击：选择节点或连接；`Shift + 单击`：多选
- 右键：上下文菜单（节点、连接、画布、多选、端口五类）
- 拖动节点：移动；拖动端口：拉出连接；拖动网络栏右缘：调整宽度
