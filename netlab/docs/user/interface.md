# 界面指南

## 顶部栏

从左到右：品牌、工作区切换（TOPOLOGY / FIELD · FEM）、当前模式、运行控制（运行 / 单步 / 重置）、
读数（t、fps、step）、时间轴、会话时钟。（帮助在「帮助」菜单，退出在「文件 → 退出服务」，窗口的最小化 / 最大化 / 关闭在顶栏最右侧，顶栏不再重复放帮助与退出按钮。）

- **运行 / 暂停**：空格；运行中按钮反色并显示暂停。
- **单步**：推进一个 `dt`。
- **重置**：清状态与时间，探针与仪器设置保留。
- **时间轴**：拖动查看历史帧（只读回放），双击回到实时。

## 菜单栏与信息条

菜单共 9 项：文件、编辑、视图、工程 · 网络、仿真、分析、工具、设置、帮助。

右侧信息条常驻 9 段：工程、网络、模式、节点/连线数、`dt`、`t`、`step`、告警数、运行状态。
信息条可以在「设置 → 视图」隐藏。

## 左侧与中间

- **网络栏**：工程内的多个网络；可新建、改名、删除，拖动右缘调整宽度。
- **工具栏**：添加节点、自动布局、适配视图、缩放、清空。
- **画布**：滚轮缩放、中键拖拽平移、拖拽节点、从端口拖出连接、双击编辑、右键菜单。
  状态栏的「栅格 / 吸附 / 捕捉点 / 正交 / 节点样式 / 图纸」可即时切换。

## 右侧面板（4 组）

1. **检查器**：选中节点或连接后的参数表单；未选中时显示空态提示。
2. **函数**：`节点函数` 与 `连接函数` 两个子页；选中节点只看节点函数，选中连接只看连接函数。
   选中对象时子页会自动跟随。
3. **模块与扩展**：模块库（`.block` 文件）与 Python 扩展两个子页。
4. **分析**：信号曲线、相图、旁路分析三个子页。

> 有限元场是独立工作区（TOPOLOGY / FIELD · FEM），不在右栏里；切换工作区会暂停另一侧的仿真。

## 设置抽屉

菜单「设置」打开右侧 460px 的非模态抽屉，左侧分「工程 / 视图 / 交互」：

- **工程**：工作模式、仿真节奏、求解器、网络统计、积分设置、模板、工程文件、画布网格、场景数据。
- **视图**：主题、强调色、动效档、UI 性能、信息条显隐。
- **交互**：启动引导、自动保存、快照间隔、快捷键入口。

抽屉打开时画布会向左让位，改动即时生效，可以边看画布边调。

## 文档窗口

「帮助」菜单或 `Ctrl+K` 打开非模态文档窗口：可拖动标题栏移动、拖右下角调整大小、双击标题栏最大化、
最小化到右下角。左侧是目录，顶部是搜索框，回车跳到第一条结果。
