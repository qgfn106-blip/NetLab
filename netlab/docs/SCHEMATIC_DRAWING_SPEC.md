# Netlab 电路图绘制规范（Agent 执行版）

> 适用：电路模式（`mode=circuit`）的符号、引脚、导线、标注、自动布局与校验。
> 本文是**可执行规范**，不是标准全文；国家标准依据见 §1，术语见 `GLOSSARY.md`，
> 决策背景见 `adr/0001-schematic-layer.md`。
>
> 最后修改：2026-10-26 05:03

## 1. 标准依据与边界

| 标准 | 用途（本项目取用的部分） |
| --- | --- |
| GB/T 4728.1/.3/.4/.5/.6~8/.11~13 | 符号形状、符号要素、导体/连接件、无源/半导体/开关/逻辑/模拟符号的**风格**依据 |
| GB/T 6988.1-2024 | 电气技术文件编制规则（图名、编号、版本、说明的组织思路） |
| GB/T 18135-2008 | 电气工程 CAD 制图规则（线型、字体、图框的总体原则） |
| GB/T 5094.1/.2 | 参照代号/结构原则（位号与参照代号的关系） |
| GB/T 4026-2025 | 端子、导体终端与导体标识（端子号/线号的后续入口） |

**边界（写死在验收里）**

- 只做「GB/T 4728 风格」的矢量线稿；**不宣称**尺寸公差、引脚间距、图框尺寸就是国标强制值。
- 不做完整图框/标题栏/多页图幅（后续阶段）；不做接线图、PCB 布局图。
- 官方标准符号库没有的自定义模块，用**功能框**并标注「自定义」，不得冒充标准符号。

## 2. 两层数据契约

### 2.1 电气拓扑层（唯一求解口径，不允许画图改语义）

```jsonc
// edge 仍表示元件；两端元件省略 pins，由 source/target 推导
{"id": "...", "kind": "resistor", "source": "<node>", "target": "<node>", "params": {"R": 1000}}

// 多端器件：pins 是电气绑定，不是画图坐标
{"id": "...", "kind": "opamp",
 "pins": {"IN+": "<node>", "IN-": "<node>", "OUT": "<node>"},
 "params": {"gain": 1e5, "vmax": 15}}
```

- `ElementSpec.pins`：`[{name, role: input|output|passive|power, required}]`。
- 绑定缺失/指向不存在节点 → 校验失败，禁止打开或运行。
- **禁止**用画图坐标反推电气连接；交叉的导线不能自动合并网络。

### 2.2 图纸布局层（可编辑、可自动生成）

```jsonc
{"edges": {"<edge-id>": {"x": 0, "y": 0, "rot": 0}},      // 元件实例
 "nodes": {"<node-id>": {"x": 0, "y": 0}},                 // 网络锚点
 "wires": {"<edge-id>": {"waypoints": [{"x": 0, "y": 0}]}}} // 可选路径折点
```

- 坐标单位=世界单位，画布 y 向下；**所有锚点/折点吸附 20 网格**（可切 10/50）。
- `rot` 只允许 **30° 的整数倍**（覆盖 0/60/90/120/180/240/270/300）。
- 手工 `layout` 优先；缺省时自动布局一次性生成并写回工程。

## 3. 符号与引脚

1. 每个符号声明**局部引脚表**：`{name, x, y, dir, bind}`；本地 +x 为符号轴。
2. 两端元件默认 `pin1=(-L/2,0)`、`pin2=(+L/2,0)`；多引脚逐一定义（运放 3 脚、DFF ≥4 脚）。
3. 引脚必须落在 20 网格（30° 旋转后若不在网格，允许 0.5 网格误差并以锚点吸附修正）。
4. 引脚位置是唯一权威：**导线端点必须等于引脚坐标（误差 ≤0.5px）**。
5. 极性元件必须画 +/− 或方向标记（二极管三角、电解电容 +、运放输入 +/−、电源极性）。
6. 符号线宽与导线同层同风格（当前 1.15–1.8），主题色只区分符号/导线，不隐藏导线。

## 4. 导线、连接点与交叉

| 规则 | 验收 |
| --- | --- |
| 默认水平/垂直；引脚轴非 H/V 时，先沿引脚轴拉一段直线，再接正交折线 | 端点贴引脚，转折点落在网格 |
| 同一电气网络 ≥3 条线相接 → 实心汇合点；2 条线不画点 | 汇合点数量=网络分支数 |
| 交叉但不相连 → 必须与汇合点视觉不同（跨线弧/断口），且数据模型无连接 | 交叉处网络数不变 |
| 拖动元件只改布局；导线自动跟随引脚，不能留下视觉断线 | 拖后端点仍等于引脚坐标 |
| 导线路径可折点/手动，但不得改变电气连接 | 拓扑校验前后一致 |

## 5. 文字与标注

- 默认**只显示位号**（R1、C2、U1…）；参数值默认隐藏，只在检查器/图纸模式显示。
- 横向导线标注在上方、纵向导线标注在右侧；文字底只垫小色块，不覆盖符号、引脚、导线、汇合点。
- 位号整图唯一；重名/缺号 → 校验报错（自动生成 `前缀+序号`）。
- 单位统一、数值与单位留空格；未设置参数显示「未配置」，不得用假默认值。
- 字体/字号/朝向统一；缩放后仍可读（矢量绘制，不贴图）。

## 6. 自动布局（确定性）

1. 从源（vsource/isource/输入端口）做拓扑分层，负载在右；反馈支路排在外侧。
2. 电源轨在上、地/参考在下；主信号从左到右。
3. 网络锚点：同层按 lane 递增 y（步长 80），x = 层号 × 160，全部吸附 20。
4. 元件实例：放在两锚点路径的中点，`rot` 对齐该段方向并量化到 30°。
5. 同层重叠：按 lane 顺序错开；有手工布局的元件完全不参与自动布局。
6. 同一输入必须生成**逐字节相同**的布局（可测试：两次生成 diff 为空）。

## 7. Agent 工作流（强制顺序）

1. 先读 `REQUIREMENTS_AND_RULES.md` 的 R18/R19 与 D33/D34，再读本文与 `GLOSSARY.md`。
2. 先定义/更新 `ElementSpec.pins` 与布局 schema，再写渲染；**不得先改渲染再补数据**。
3. 求值路径（MNA/Newton）零改动；用测试证明 `scene.step` 前后拓扑/结果不变。
4. 每加一个符号：引脚表 + 绑定校验 + 绘制 + 快照截图 + 至少 1 个行为/几何断言。
5. 交付必须附：截图（1440 宽）、校验清单勾选、测试数、已知未做项；不虚构完成度。

## 8. 验收清单（复制到票单勾选）

- [ ] 每个元件有唯一 id/位号；位号冲突可检测
- [ ] 每个引脚有局部坐标、方向、电气绑定；绑定节点存在
- [ ] 导线端点=引脚坐标；折点/锚点在网格
- [ ] ≥3 线相接有汇合点；交叉不相连且视觉可区分
- [ ] 拖动元件/折点不改变网络拓扑（拓扑校验通过）
- [ ] 默认只显示位号；文字不遮挡符号/导线/汇合点
- [ ] 自动布局确定（两次生成 diff 为空），手工布局保存/加载一致
- [ ] 电路图截图可读；`pytest`、`compileall`、`--selftest` 通过
- [ ] 文档：R19/D34 现状、PROGRESS 证据、票单状态同步

## 9. 软件默认规则对照（用户核对表）

| 功能区域 | 默认规则 | 验收 |
| --- | --- | --- |
| 符号库 | 标准元件用对应符号；自定义模块用功能框并标注「自定义」 | 符号与元件类型一致 |
| 元件编号 | 自动生成唯一参照位号（前缀+序号） | 新增/复制/删除后无冲突 |
| 参数标注 | 默认只显示位号；参数在检查器/图纸模式显示，单位统一 | 文字不遮挡符号/导线/节点 |
| 导线绘制 | 默认水平/垂直/直角；非 H/V 引脚先沿轴再接折线 | 路径清晰，拓扑不变 |
| 连接点 | 真实连接用实心汇合点；≥3 线才画 | 连接状态与内部拓扑一致 |
| 非连接交叉 | 跨线弧/断口明确区分，数据模型不合并 | 不会意外短接网络 |
| 节点拖动 | 只改锚点/布局，导线自动跟随 | 无视觉断线，拓扑校验通过 |
| 端口设置 | 显示引脚名与极性；错误绑定报错 | 接错端口能提示 |
| 模块化电路 | 有明确输入/输出端口 | 内外连接可追踪 |
| 导出/打印 | 图框/标题/图名/编号/版本（后续阶段）；黑白可辨 | 图面清晰、信息完整 |
| 设计校验 | 悬空引脚、未绑定端口、未配置参数、位号冲突 | 能报告对象与原因 |
