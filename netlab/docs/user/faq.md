# 常见问题

## 为什么打开页面后仿真没有自动运行？

从 2026-10-28 的 R30 起，任何工作模式启动后都保持停止状态，必须手动点「运行」或按空格。
这是为了避免一打开页面就持续耗算力，也让「先选场景、再运行」的流程更清楚。

## 怎么恢复示例网络？

引导页底部有「打开示例工程（信号链）」，或在设置抽屉的工程页选择模板。
若想回到空白场景：设置 → 工程 → 工作模式，切换一次即可重建。

## 切换工作模式会丢数据吗？

会。切换会用该模式的空白模板替换当前场景，节点、连接、参数与录制都会清空。
切换前会弹确认框；请先把需要保留的内容「保存工程」或「导出场景 JSON」。

## 曲线是空的？

- 先确认已点「运行」，且采集还在进行；
- 在「分析 · 信号」里勾选变量（可先在搜索框筛选）；
- 电路模式需要至少一个接地的参考节点，否则 MNA 会报错；
- 时间窗太短或太长都会让曲线看起来像直线，试试点「适配」或调整时间窗。

## 深色主题下画布还是浅色？

画布取色跟随 `html[data-theme]`；如果刚切主题，画布会在下一帧重绘。若仍有大面积浅色，
请确认使用的是 3.9.0 之后的前端资源（浏览器强刷 Ctrl+F5）。

## 动效太慢 / 电脑卡？

设置 → 视图：把「动效程度」调到「关」，把「UI 性能」调到「性能」。性能档会关闭模糊与阴影，
并限制画布像素比；这两个偏好保存在全局 `settings.json`，下次启动仍然生效。

## 设置保存在哪里？

- 外观/引导/自动保存：`%APPDATA%/Netlab/settings.json`（可用 `NETLAB_SETTINGS_DIR` 覆盖）。
- 图纸风格、GB 符号、网格、节点样式：随工程 `.netlab` 保存。
- 侧栏宽度、回放速度、信息条显隐：浏览器 localStorage。

## 自动保存会不会覆盖我的工程？

不会。自动保存只写工程目录的 `backups/` 快照，不改正本；可在「文件 → 恢复自动保存」里挑选快照。

## 端口被占用 / 打不开页面？

退出应用时会调用 `/api/shutdown` 释放端口。如果异常退出，重新运行 `start_desktop.bat` 即可；
端口在 1 秒内通常可复用。桌面模式会自动处理浏览器打开。

## 文档搜索不到？

文档只包含用户向内容（欢迎、界面、术语、FAQ、快捷键），实现细节在仓库的 `docs/` 里。
搜索按段落匹配，试试更短的关键词，例如「回放」「MNA」「动效」。
